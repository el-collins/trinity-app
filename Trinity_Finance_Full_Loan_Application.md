# **Document Overview**

This document contains all application forms and question sets used by Trinity Finance for loan origination and debt relief services. Every applicant begins with the Finance Quick Application, which captures core business and financial information. Based on the loan type selected, the applicant is then routed to the appropriate loan-specific application.

## **Application Flow**

All applicants start with the Finance Quick Application (Section 1). Based on the answer to “What Type of Loan Would You Like to Apply For?” the applicant is directed to one of the following loan-specific applications:

| Question / Field | Input Type | Options / Notes |
| :---- | :---: | :---- |
| Section 1: Finance Quick Application | *Text Entry* | Required for all applicants |
| Section 2: Equipment Finance Application | *Text Entry* | If equipment financing selected |
| Section 3: Invoice Factoring Application | *Text Entry* | If invoice factoring selected |
| Section 4: Invoice Financing Application | *Text Entry* | If invoice financing selected |
| Section 5: Line of Credit Application | *Text Entry* | If line of credit selected |
| Section 6: Merchant Cash Advance (MCA) | *Text Entry* | If MCA selected |
| Section 7: SBA Loan Application | *Text Entry* | If SBA selected |
| Section 8: Unsure of Loan Type Application | *Text Entry* | If applicant needs guidance |
| Section 9: Direct Funnel Debt Relief | *Text Entry* | Standalone debt relief path |

## **Form Notation Key**

The following notation codes indicate the type of input field or system behavior for each question:

| Question / Field | Input Type | Options / Notes |
| :---- | :---: | :---- |
| (DD) Dropdown | *Dropdown* | Applicant selects from a predefined list |
| (BB) Bubble Box / Select One | *Select One* | Applicant selects one option (radio button) |
| (MV) Monetary Value | *Dollar Amount* | Dollar amount; use full monetary numbers |
| (NV) Number Value | *Number* | Numeric entry only |
| (MW) Multiple Written Answers | *Multiple Entries* | Multiple text entry boxes |
| (MWMV) Multiple Written \+ Monetary | *Entry \+ Dollar Amount* | Paired text \+ dollar amount entries |
| (H) Hidden / Conditional | *Conditional* | Appears only when a specific prior answer is given |
| (AA) Auto-Applied | *Auto-Generated* | System-generated (e.g., date stamp) |
| (S) Signature | *Signature* | Drawn signature by applicant |
| Text Entry (no code) | *Text Entry* | Standard typed text response |

*Conditional questions are marked with “If applicable” throughout this document and appear only when triggered by a specific prior answer.*
